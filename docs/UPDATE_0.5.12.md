依使用者指定，授權由 MIT 改為 MIT + Commons Clause：原始碼可使用與修改，但不得販售本軟體或以其為主要價值的付費產品／服務，更名或換 LOGO 不影響；用於製作商業遊戲允許。0.5.11（含）以前已發布版本維持 MIT。同步 LICENSE、package.json（`SEE LICENSE IN LICENSE`）、四語 README 與打包腳本的第三方聲明文字。

注意：Commons Clause 不是 OSI 認定的開源授權；此變更非法律意見，如需確保效力請另請法律專業人士檢視。沒有應用程式碼變更；打包腳本字串改動未實際執行 `pack:zip`。
